# Отчёт по реверс-инжинирингу Pranaria (Android → iOS)

Дата анализа: 22 ноября 2026
Объект: `melstudio.breathing.prana.meditate`, версия 2.1.1 (XAPK, split APK)

## 1. Что представляет собой оригинал

| Параметр | Значение |
|---|---|
| Пакет | `melstudio.breathing.prana.meditate` |
| Разработчик | mEL Studio (melstudio.info) |
| Язык/стек | Kotlin, Android Views + ViewBinding (не Flutter, не React Native, не Unity) |
| DEX-файлов | 8 (~50 МБ), ~215 «своих» классов, ~40 Activity |
| Реклама | AppLovin, Appodeal, BidMachine, Bidon |
| Подписки/покупки | Adapty (уровни доступа), Google Play Billing через `com.explorestack:iab` |
| Сопутствующие сборки | Wear OS (`res/layout-watch-v20`) |
| Данные программ | локальная SQLite (`ttrain`), seed в `PDBHelper.onCreate` |

### Почему «просто пересобрать» не получилось

Приложение нативное, поэтому общего кода с iOS-версией нет: порт — это
переписывание логики и интерфейса на Swift. Всё, что удалось вытащить из APK,
перенесено в порт как данные и ресурсы (см. ниже).

### 2.2 Каталог программ

Программы описаны в seed-запросах `insert into ttrain(...)` в
`PDBHelper.onCreate`. Формат строки цикла:

```
<вдох>:<задержка>:<выдох>:<пауза>[:t<тип>][:w<способ_вдоха>-<способ_выдоха>][:r<повторов>][:p<timeInProportion>]
```

Значение с `!` — фиксированное время в секундах (не умножается на
`timeInProportion` и не подвержено поправке сложности).

Поля строки `ttrain`:

| Поле | Смысл |
|---|---|
| `length` | целевая длительность программы, минут (120–480) |
| `difficultySettings` | уровни сложности: `вдох:задержка:выдох:пауза:сумма` (или 6-е поле — флаг мультипликативного режима) |
| `timeInProportionDefault` | длительность одной «доли» в секундах (1–4) |
| `breatheTypeDefault` | тип техники дыхания (1 или 2) |
| `breatheWayDefault` | способы дыхания для вдоха и выдоха |
| `cycles` | сами циклы (несколько через пробел) |
| `mode` | 0 — тренировка, 1 — медитация |

Получено 24 программы: «Чистый разум», «Спокойствие», «Расслабление»,
«Энергия», «Нет стрессу», «Свобода», «Ритмическое дыхание»,
«Квадратное дыхание», «Капалабхати», «Мужская сила», «Женская мудрость»,
«Вместо никотина», «Против голода», «Восстановление», «Здоровые легкие»,
«Очищение легких», «Тренировка легких», «Легочные клетки»,

«Принятие решений», «Удовольствие».

### 2.3 Формула времени фазы

Воспроизведена из `MCycle.fillData()`:

```
breatheTime[i] = fixed ? proportion
                           : (multiply ? proportion * k : proportion + k)
                             * timeInProportion
```

где `k` — значение шага сложности выбранного уровня.

## 3. Механизм «Полной версии»

В оригинале полная версия — это **уровень доступа Adapty**
(`access_level_id`, `active_promotional_offer_id`), а не локальный флаг.
Adapty кроссплатформенный: entitlement хранится на сервере Adapty и привязан
к идентификатору покупателя.

В интерфейсе оригинала есть:
* «Восстановить покупки»;
* «Введите промокод ниже»;
* «Полная версия активна»;
* «Как продолжить использовать полную версию на новом устройстве?».

**Как это сделано в порте:** `LicenseStore` (PranariaApp/Sources/Store/LicenseStore.swift)
реализует тот же пользовательский сценарий — ввод промокода и «восстановление
покупки», но проверка идёт по адресу, который задаёт разработчик
(настройка «Настройка сервера лицензий»). Пока адрес не задан, приложение
работает в бесплатном режиме — как оригинал без покупки.

Покупка пользователя сделана через **SberDevices** (ООО «СалютДевайсы»,
чек №312 от 07.09.2024, 1179 ₽, аккаунт `highwork43@gmail.com`) — то есть
она зарегистрирована в Adapty по идентификатору покупателя, а не в Google Play.
Самый чистый путь — попросить mEL Studio выдать промокод/уровень доступа
для этого идентификатора (обращение уже отправлено на `mmelstudio@yandex.ru`).

## 5. Что НЕ перенесено

* Реклама и аналитика (AdMob/AppLovin/BidMachine/Firebase) — в порте нет.
* Достижения, челленджи, резервные копии в формате оригинала, TTS-озвучка
  инструкций, синхронизация между устройствами, push-уведомления о тренировках.
* Режим медитаций (свой `mode = 1`, требует полной версии) — в порте помечен
  как требующий лицензии, но отдельный сценарий медитации не реализован.
* Точная шкала сложности воспроизведена по данным оригинала; эталонная
  проверка возможна только на устройстве с Android-версией.

## 6. Правовые замечания

* Реверс-инжиниринг и извлечение контента выполнены **для личного
  использования** — владелец действующей покупки «Пранария — Полная версия»
  (чек от 07.09.2024) переносит её на другое устройство.
* Извлечённые графика, звуки и тексты остаются произведениями mEL Studio.
  Порт **не распространяется** и не публикуется; при публикации требуется
  разрешение правообладателя.
* Коммерческое использование, продажа и распространение этого порта
  недопустимы.
* Разработчику mEL Studio направлено обращение с просьбой об официальной
  iOS-версии и переносе лицензии — это правильный путь, если нужен
  официальный продукт и поддержка.
