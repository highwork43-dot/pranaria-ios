# Установка на iPhone 16 Pro Max по кабелю

Сборка iOS-приложения возможна только на macOS (Xcode). Поэтому .ipa собирается
в облачном CI (GitHub Actions, бесплатный раннер `macos-14`), а на телефон
ставится переподписанным.

## Шаг 1. Получить .ipa

```bash
bash Tools/ci.sh          # собрать в CI и скачать артефакт
# или только скачать последний:
bash Tools/ci.sh --download
```

Результат: `build/Pranaria-unsigned.ipa`.

## Шаг 2A. Установка с Linux (Sideloadly)

1. Установить iTunes для Linux и утилиты libimobiledevice:

   ```bash
   sudo apt-get install -y libimobiledevice-utils ideviceinstaller usbmuxd
   # iTunes: пакет из ubuntu archive (libimobiledevice6 + iTunes .deb)
   ```
2. Скачать Sideloadly: <https://sideloadly.io/> (версия для Linux, AppImage).
3. Подключить iPhone по кабелю, на телефоне нажать «Доверять этому компьютеру».
4. Запустить:
   ```bash
   chmod +x Sideloadly*.AppImage
   sudo ./Sideloadly*.AppImage
   ```
5. В окне Sideloadly:
   * перетащить `Pranaria-unsigned.ipa`;
   * в поле Apple ID вписать **свой** Apple ID (например `highwork43@gmail.com`);
   * нажать **Start**;
   * на телефоне подтвердить вход в Apple ID (系统弹窗 → «Отправить» код);
   * дождаться установки.

С бесплатным Apple ID приложение работает **7 дней**, затем его нужно
переустановить (или использовать AltStore для автопродления).

## Шаг 2B. Установка с Mac (Xcode — проще всего)

```bash
brew install xcodegen
cd pranaria-ios
xcodegen generate
open Pranaria.xcodeproj
```

В Xcode: Settings → Accounts → добавить Apple ID → выбрать свой iPhone в
списке устройств → Run (⌘R). Приложение установится по кабелю.

## Шаг 3. Настройка iPhone

1. Настройки → Основные → VPN и управление устройством → доверять
   разработчику (появится после первой установки).
2. «Пранaрия» → Настройки → Полная версия: статус «Полная версия активна»
   (лицензия встроена в приложение и подписана).
3. Настройки → Основные → язык и регион → Русский — интерфейс на русском.

## Проверка после установки

| Что проверить | Где |
|---|---|
| Каталог 24 программ | вкладка «Тренировки» |
| Запуск тренировки, анимация круга | «Квадратное дыхание» → «Начать» |
| Звуки фаз и фоновая музыка | во время тренировки |
| Голосовые инструкции | Настройки → Голосовые инструкции → «Озвучивать фазы» |
| Полная версия | Настройки → Полная версия |
| Достижения | вкладка «Достижения» |
| Аналитика | вкладка «Аналитика» |
| Прогресс и серия дней | вкладка «Прогресс» |

## Если приложение не запускается

* **Не установлено** — проверьте, что доверяете сертификату разработчика
  (Настройки → Основные → VPN и управление устройством).
* **Вылетает при старте** — скорее всего, в бандле нет `programs.json`:
  убедитесь, что в .ipa есть `Programs.json` (файл должен быть в корне бандла,
  имя с заглавной — так его добавляет Xcode).
* **Нет звука** — проверьте, что на iPhone не включён беззвучный режим и
  выбран «Режим разработчика» в Настройки → Звуки.
