# Пранария — iOS-порт

Личная сборка приложения «Дыхание: дыхательные практики» (Pranaria,
разработчик mEL Studio) для iPhone. Сделана через реверс-инжиниринг
Android-версии: из APK извлечены программы, звуки и графика, а логика
переписана на SwiftUI.

* Что и как извлечено — [docs/RE-NOTES.md](docs/RE-NOTES.md)
* Как собрать и поставить на iPhone — [docs/BUILD.md](docs/BUILD.md)

## Что внутри

```
pranaria-ios/
├── project.yml                     # описание проекта для XcodeGen
├── Content/
│   ├── Audio/                      # 12 звуков (фон, метроном, сигналы фаз)
│   ├── Images/                     # 199 PNG (иконки, фоны, достижения)
│   └── programs.json               # каталог 24 программ с параметрами
├── PranariaApp/Sources/
│   ├── App/                        # точка входа и вкладки
│   ├── Models/                     # Program, ProgramPlan, BreathPhase
│   ├── Engine/                     # движок сессии, звук
│   ├── Store/                      # каталог, прогресс, лицензия
│   └── Views/                      # библиотека, тренировка, прогресс, настройки
├── Tools/
│   ├── extract_content.py          # аудио + изображения + строки из APK
│   └── extract_programs.py         # каталог программ из декомпилированного кода
└── docs/
```

## Возможности

* 24 программы дыхания из оригинала — с реальными пропорциями фаз,
  уровнями сложности, описаниями и иконками;
* анимированный дыхательный круг, сигналы смены фазы, фоновая музыка и
  метроном (файлы взяты из оригинала);
* уровни сложности (до 25 уровней) с корректным пересчётом времени фаз;
* прогресс: серия дней, суммарное время, график за неделю, статистика по
  программам, экспорт/импорт прогресса в JSON;
* экран «Полная версия» с промокодом и восстановлением покупки — по тому же
  сценарию, что в оригинале (уровень доступа Adapty).

## Что не перенесено

Реклама и аналитика, достижения, челленджи, TTS-инструкции, push-уведомления,
собственный формат резервных копий оригинала. Подробности — в отчёте.

## Ограничения

* Сборка требует macOS + Xcode (или облачный CI) — см. BUILD.md.
* Полная версия активируется промокодом, который выдаёт разработчик;
  настраивается в «Настройки → Полная версия».
